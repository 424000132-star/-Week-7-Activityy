# Dart Student Purchase Program

**Name:** Raniel Piollo A. Camarador
**Section:** BSIT 2.1

## Description

This program is a simple Dart program that calculates the total price of items purchased by a student. It also checks if the student can get a discount and calculates the remaining items, groups of two, and extra items.

## Dart Features Used

* `int` - used for quantity and item calculations
* `double` - used for the price and total price
* `String` - used for the student name
* `bool` - used for student status and discount eligibility
* Arithmetic operators - `*`, `-`, `~/`, and `%`
* Comparison operator - `>=`
* `print()` - used to display the results

## How to Run

This program was created and tested using DartPad.

To run the program using Dart:

```text
dart run
```
